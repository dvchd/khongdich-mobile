# Khong Dich Mobile v0.11.0

## New features

- **Story honor badge on story detail**: stories with an honor show its image
  (static/animated) below the author name, above the genre badges — same
  position as web; long-press to see the honor name.
- **Browse stories by honor**: tap the honor image on story detail to open
  stories carrying the same honor; Home adds a **Danh** shortcut (next to
  BXH / Genres / Tags) opening the honor list with full-width images, names
  and story counts.

## Tech

- 264 tests green, `flutter analyze` clean.
- Backend: `/api/v1/mobile/danh` + `/api/v1/mobile/danh/{id}` (deployed to prod).
