# KhongDich Mobile v0.13.1

## Fixes

- **Audio listening no longer reads links aloud**: every link form in a
  chapter (`[text](url)`, spaced `[text] (url)`, reference links, `<a>/<img>`
  HTML tags, bare `https://...` URLs) is stripped from speech — only the link
  text is kept. The previous fix only covered image links, so plain links
  were still read out.
- **No leftover link tails**: URLs containing parentheses (e.g. `anh (1).png`)
  are removed cleanly, no more stray `.png)` in speech.

## Technical

- 271 tests green, `flutter analyze` 0 issues.
- Mirrors the backend: web TTS strips links the same way (deployed to demo).
