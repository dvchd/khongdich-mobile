## New features

- **Trust score on profile**: 🎯 Trust badge with progress bar + score /100 (color-coded: green ≥70, yellow ≥40, red <40) — same as web.
- **Authors can download chapter audio**: "Download chapter audio" button in the listening control panel — synthesizes the whole chapter into one WAV file using the selected voice, share/save via the Android system. Only visible to the story's author.
- **Share QR image**: "Share QR image" button in the QR dialog — save the image or send it via other apps.

## Bug fixes

- **Plain-text chapters no longer lose line breaks**: plain text chapters now break lines exactly like the web — previously lines were joined into one block.
- **Chapter content auto-refreshes when the author edits**: the chapter cache detects stale content and refetches — no more manual delete-and-redownload.
- **More scannable QR codes**: error correction raised to level H (30%) + rounded-logo background — scans reliably even on bright screens.
- **Thorough image-cache cleanup**: also removes orphan files not tracked by the cache index.

## Improvements

- Long-lived image cache (10 years) — re-reading previously viewed stories doesn't re-download images.
- "Clear image cache" button shows cache size in Settings.
