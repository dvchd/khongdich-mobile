## Bug fixes

- **Google Sign-In is much more reliable**: previously it would intermittently fail with "Account reauth failed", forcing repeated sign-in attempts. Now the app automatically re-authenticates when Google requests it — no re-entering credentials, and the account picker only appears when truly needed.
- **"Log out" button only shows when logged in** — it used to always appear, which was confusing.
- **Fixed navigation**: "Back to story" and "View downloaded stories" now return to the previous screen correctly (previously a swipe-back could exit the app).

## Tech

- Platform upgrades: Flutter 3.47, riverpod 3.4, go_router 17, dio 5.11 — more secure (flutter_secure_storage 11), fewer navigation edge cases.
- Release builds are always signed with the real release key (no more debug-signed local builds).
- 166 tests green, `flutter analyze` 0 issues.
