# Không Dịch Mobile v0.13.0

## Tính năng mới

- **Tìm kiếm/lọc đa thể loại + đa tag (AND)**: màn Tìm kiếm chọn nhiều thể
  loại/tag cùng lúc — chỉ hiện truyện thuộc TẤT CẢ mục đã chọn, giống web
  /tim-kiem. Chip hiện số lượng đã chọn, bottom sheet checkbox có nút Áp dụng.
- **Khám phá thêm hàng Thể loại/Tag đa chọn**: mỗi chip toggle độc lập, có
  nhãn “đa chọn” và đếm số đang chọn để phân biệt với hàng chọn 1; nút Xoá lọc
  hiện khi có filter đa chọn.
- **Danh sách Thể loại/Tag có chế độ “Chọn nhiều”**: tick nhiều mục rồi bấm
  “Xem truyện kết hợp” để mở thẳng màn tìm kiếm với filter dựng sẵn.
- **Phân biệt single/multi**: chip đa chọn luôn có avatar “+”, sheet chọn ghi
  rõ “đa chọn” — không còn nhầm với chip/sheet chọn 1.

## Sửa lỗi

- Màn chi tiết thể loại/tag về đúng 1 slug như web (bỏ lọc chéo thử nghiệm
  gây rườm rà); empty state gọn gàng.

## Kỹ thuật

- 268 tests xanh, `flutter analyze` 0 lỗi.
- Repository gửi filter dạng comma-joined (`category=a,b`), tương thích API
  backend mới (MultiQuery gộp key trùng).
