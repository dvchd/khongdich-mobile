# Khong Dich Mobile v0.8.0

## New features

- **In-app update notices** (Play In-App Updates): when Google Play has a new
  version, Home shows an update banner — tap to download in the background
  via Play, then "Install now" without leaving the app.
- "Later" hides the banner for the session; every unsupported case (not
  installed from Play, offline, release still processing) stays silent.

## Bug fixes

- **Market chat**: a flapping server (accepts a connection then closes it
  instantly) used to trigger endless ~1s reconnect loops, draining battery
  and data — backoff now doubles properly and only resets after a stable
  connection of 60 seconds or more.
- Server logs now report the real app version (was hardcoded "0.3").

## Tech

- 252 tests green (+18), `flutter analyze` clean.
