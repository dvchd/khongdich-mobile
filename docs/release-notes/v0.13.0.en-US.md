# KhongDich Mobile v0.13.0

## New features

- **Multi-category + multi-tag search/filter (AND)**: the Search screen can
  select several categories/tags at once — only stories matching ALL selected
  items are shown, mirroring web /tim-kiem. Chips show the selection count,
  and the bottom sheet uses checkboxes with an Apply button.
- **Explore gains multi-select Category/Tag rows**: each chip toggles
  independently, with a “multi” label and selection count to distinguish them
  from single-select rows; a Clear-filters button appears when active.
- **Category/Tag lists gain a “Select multiple” mode**: tick several entries
  then tap “View combined stories” to open Search with the filter preset.
- **Single vs multi disambiguation**: multi chips always carry a “+” avatar,
  picker sheets are labeled multi — no more confusion with single-select.

## Fixes

- Category/tag detail screens are back to a single slug like web (removed the
  experimental cross-filter that cluttered the pages); tidy empty states.

## Technical

- 268 tests green, `flutter analyze` 0 issues.
- Repository sends comma-joined filters (`category=a,b`), matching the new
  backend API (MultiQuery merges duplicate keys).
