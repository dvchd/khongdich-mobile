# Không Dịch Mobile v0.12.0

## New features

- **Unrevealed title images now show a lock icon 🔒**: the title list and the
  stories-by-title screen show a lock placeholder instead of a trophy icon or
  hiding the image entirely — matching the web. Each day the system reveals one
  new title image (per the reveal mode configured by admins); **title names are
  always visible** for browsing and to build curiosity.

## Tech

- 264 tests green, `flutter analyze` clean.
- `DanhSummary` / `DanhInfo` models now parse the `revealed` flag from the API —
  the app can tell "not revealed yet" (lock) from "no image" (trophy).
