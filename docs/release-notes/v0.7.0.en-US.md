# Không Dịch v0.7.0

## New features

- **SRT subtitles for authors**: the TTS share sheet now offers an `.srt` file alongside
  the `.wav` — cues generated per sentence from the engine with real per-chunk timing
  (both gTTS and cloud engines).
- **"My Stories"**: the Profile tab gets a new section listing all of an author's works —
  drafts, pending review and published — tap through to the story page.

## Bug fixes

- **Images in text chapters not showing** (especially after offline reading): root cause
  was the image cache missing the `ImageCacheManager` mixin; added a dedicated
  `ImageBlock` for standalone images, captions only render when explicit.
- **Chat rewritten to match the web** (`chatFullReader`): typing indicator, fake input bar
  that types out then **waits for Send**, right-aligned bubbles for your own messages,
  web-style action/narration; removed the "See all" button (web doesn't have it).
- **Chat: series of timing fixes** — double-start typewriter on consecutive "you"
  messages, dead tap after the typing indicator, timer slot released after firing,
  "Tap/Send to continue" hints now in the scroll flow (no longer glued to the bottom),
  bottom SafeArea for the input bar.
- **Comments**: compatible with backend pagination by root entry (`totalComments`).
- **TTS**: pause playback before synthesizing chapter audio — no more permanent hang.

## Tech

- 234 tests green, `flutter analyze` clean.
