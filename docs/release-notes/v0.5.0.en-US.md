## New features

- **Complete offline reading**: downloading chapters now also saves story info + cover — the offline story detail looks identical to online. Downloaded stories get a hybrid reader: 100% offline reading, continuous reading/listening when online. Old downloads missing covers are backfilled automatically when opening the Library.
- **Web-style search filters**: sort, status, story type, genre, tag + pagination.
- **New "Top flop" section on Home**, per-section refresh, comment counts as badges.
- **Story detail refresh**: big cover + markdown description, follow button inline with the author name, author trust score, QR share sheet.
- **Web-mobile style reader**: chapter header (Ch. N: Title + read time/word count/share/report), chapters show word count + view count, floating "Next chapter" pill replaces the end-of-chapter block, scrolling past the end reveals a continue button.
- **Page-flip fills pages**: paragraphs split at exact page boundaries keeping inline formatting (italic/bold/link/code) — pages are nearly never half-empty.
- **Seamless listening**: global now-playing bar, tapping the notification returns to the chapter being read, Library condensed to 4 tabs.

## Bug fixes

- Follow button no longer stuck at "Processing…".
- Fixed 3 runtime bugs from 0.4.2: reader crash on open, error on app resume, now-playing bar not hiding when the listening panel opens.
- Back button works again on screens without the bottom navigation bar.
- Search no longer 404s when choosing a sort order.
- No more skipping 2 chapters at once; short chapters now allow tapping previous/next.
- Network errors now show a friendly screen with a retry button.
- Comment-count badge no longer disappears when reopening a cached chapter.
- Google sign-in works on every local build (signed with the real keystore).
