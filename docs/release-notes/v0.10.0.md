# Không Dịch Mobile v0.10.0

## Tính năng mới

- **Trang chủ gọn gàng, dễ hiểu hơn**: thanh tiêu đề thêm icon app cạnh tên
  "Không Dịch"; nút đăng truyện đổi từ icon cây bút trơ thành nút chữ
  **"Đăng truyện"** — bấm vào vẫn mở hướng dẫn đăng truyện trên web.

## Sửa lỗi

- **Khám phá lọc đúng kết quả**: chọn Trạng thái (Đang ra / Hoàn thành /
  Tạm dừng) hoặc Nội dung (Truyện chữ / Bách khoa / Manga / Chat / Video)
  giờ thực sự thay đổi danh sách — trước đây backend bỏ qua bộ lọc khi sort
  là Mới nhất / Hot / Hoàn thành. Sắp xếp cũng đồng bộ với web /kham-pha:
  thêm "Dài nhất" (theo số chương), bỏ sort "Hoàn thành" trùng nghĩa với bộ
  lọc Trạng thái.
- **Tìm kiếm — sheet Thể loại và Tag hết trống**: danh sách được tải ngay
  trong sheet kèm trạng thái đang tải / lỗi có nút thử lại (trước đây đọc
  provider chưa fetch nên sheet mở ra rỗng không có gì).
- **Nghe đọc bỏ qua ảnh đính kèm**: TTS không còn đọc link/file ảnh markdown
  trong truyện chữ và bách khoa — nhận diện được cả cách viết `![alt] (url)`
  có khoảng trắng, và gỡ nốt cú pháp ảnh hỏng (URL chứa ký tự lạ) trước khi
  đưa vào engine. Web TTS cũng được vá tương tự (`chapter_to_tts_text`).

## Kỹ thuật

- 264 tests xanh (+3 test ảnh/TTS), `flutter analyze` 0 lỗi.
- Đi kèm bản backend: `GET /api/v1/mobile/stories` áp filter status/
  content_type/category cho mọi sort (cần deploy backend `khongdich` để màn
  Khám phá lọc đúng).
