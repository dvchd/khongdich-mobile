# Không Dịch Mobile v0.10.0

## New features

- **Cleaner, clearer Home**: app icon next to the "Không Dịch" title in the
  app bar; the publish shortcut changed from a bare pencil icon to a labeled
  **"Đăng truyện"** button — still opens the publish-on-web guide.

## Bug fixes

- **Explore filters actually filter**: picking a status (ongoing / completed /
  on hiatus) or content type (text / encyclopedia / manga / chat / video) now
  really changes the list — the backend used to silently ignore these filters
  for the Mới nhất / Hot / Completed sorts. Sort options now mirror the web
  /kham-pha page: added "Dài nhất" (by chapter count), removed the "Hoàn
  thành" sort that duplicated the status filter.
- **Search — category & tag sheets no longer empty**: the lists now load
  inside the sheet with loading/error + retry (previously the sheet read a
  provider that had never been fetched, so it opened blank).
- **Listening skips attached images**: TTS no longer reads image links/file
  names embedded as markdown in text and encyclopedia chapters — including
  the spaced `![alt] (url)` form, with a safety net that strips malformed
  image syntax before it reaches the engine. Web TTS got the same fix
  (`chapter_to_tts_text`).

## Tech

- 264 passing tests (+3 image/TTS tests), `flutter analyze` clean.
- Paired backend change: `GET /api/v1/mobile/stories` now applies
  status/content_type/category filters for every sort (deploy the `khongdich`
  backend for Explore filtering to take effect).
