## New features

- **Discovery-first home**: Market section moves to the top (auto-hides when closed), followed by Continue reading → Random → Freshly updated → Top flop → Trending now — new content is front and center on launch. "New stories" renamed to "Freshly updated" with its own refresh button.
- **VIP stories rail**: VIP ranking placed right after Trending, auto-hidden when empty.
- **Content-type chips**: Manga/Chat/Video stories show a badge on their cover.
- **Dismissible offline hero card**: tap X to hide it permanently; the info moves to the Profile tab and can be re-enabled in Settings → Configuration.
- **Re-tap active tab to refresh**: tapping Home again refetches the feed with a fresh random set; Search re-runs your query or pulls new random stories.
- **Shimmer loading skeleton** on the home screen.

## Bug fixes

- Fixed a latent environment issue: stale env data from older builds can no longer point a prod binary at the demo server.
- Hero card gradient has better contrast in light theme.

## Technical

- Architecture refactor: extracted `OfflineChapterReader` from the router, split DTOs out of `story_repository`, removed `ApiClient` dead code.
- 206 tests green, `flutter analyze` clean.
