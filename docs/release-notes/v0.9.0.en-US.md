# Không Dịch Mobile v0.9.0

## New features

- **Voice update guide** in the TTS control panel: voices come from the
  on-device TTS engine (Google/Samsung), not the app. When your voice sounds
  outdated or Vietnamese data is missing, this new step-by-step sheet opens
  Google Play to update the Google engine, jumps straight into the system
  Text-to-speech settings to download voice data, and links the Galaxy Store
  for high-quality Samsung voices. Closing the sheet reloads the voice list.
- Friendly engine display names ("Google (Speech Recognition & Synthesis)"
  instead of raw package names).

## Bug fixes

- **Exported audio now matches the speed you hear**: playback and export used
  different rate mappings — listening at 2.5x produced a file twice as fast.
  Both now share one mapping function, and pitch/volume/rate are re-applied on
  every export (a second download with a new speed is correct too).
- **Update banner recognizes a build already downloaded in a previous
  session**: if you downloaded an update but closed the app before installing,
  the next launch goes straight to "Install now" instead of offering another
  download (that state used to hang the flow).
- "Install now" no longer hangs forever when the in_app_update plugin never
  resolves (known plugin 5.0.0 bug) — 30s timeout added; Play restarts the app
  automatically on success.

## Technical

- 261 tests green (+9: locking the speed formula and the voice-guide flow),
  `flutter analyze` clean.
