# Không Dịch Mobile v0.8.0

## Tính năng mới

- **Thông báo cập nhật trong app** (Play In-App Updates): khi CH Play có bản
  mới, Trang chủ hiện banner mời cập nhật — bấm là tải ngầm qua Play, xong
  chạm "Cài ngay" để cài tại chỗ không cần rời app.
- "Để sau" ẩn banner trong phiên; mọi trường hợp không dùng được (không cài
  từ Play, mất mạng, bản mới đang xử lý) đều im lặng, không làm phiền.

## Sửa lỗi

- **Chợ Phiên**: server tạm gián đoạn kiểu "chấp nhận kết nối rồi đóng ngay"
  từng khiến app kết nối lại mỗi ~1s vô hạn (tốn pin + dữ liệu) — giờ
  backoff tăng dần đúng thiết kế, chỉ reset khi kết nối ổn định ≥ 60s.
- Server log giờ nhận đúng phiên bản app (trước đây luôn báo "0.3").

## Kỹ thuật

- 252 tests xanh (+18), `flutter analyze` 0 lỗi.
