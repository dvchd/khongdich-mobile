# Không Dịch Mobile v0.10.1

## New features

- **Search finds author channels**: type an author's name / @username (or an
  unaccented display name) — results show a top **"Tác giả" (Authors)**
  section with avatar, name, @username, story and follower counts; tapping
  opens the author's channel page directly. Mirrors the web search and the
  prod backend.

## Bug fixes

- **Author names starting with an emoji render correctly**: avatar fallback
  now uses the first character safely via surrogate-pair-aware extraction
  (some emoji names previously broke the leading character in the avatar).
- **Compact author channel meta**: "theo dõi" shortened to match web display.

## Tech

- 264 passing tests, `flutter analyze` clean.
- Paired backend change: `/api/v1/search` returns the `authors` array
  (already deployed to prod).
